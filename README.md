# SEO Website Auditor

Crawl a website, list technical SEO issues, export an Excel report, and generate an AI strategy brief.

Files: `app.py` (web interface), `auditor.py` (crawler and analysis), `requirements.txt`.

Optional secrets (Streamlit app settings -> Secrets):
```
APP_PASSWORD = "choose-a-password"
GEMINI_API_KEY = "your-free-key-from-aistudio.google.com"
```
